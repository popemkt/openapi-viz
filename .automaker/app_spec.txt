  <project_name>OpenAPI Visualization</project_name>

  <overview>
    A modern web application for visualizing OpenAPI specifications as interactive graphs. The application enables API architects, developers, and technical writers to explore API structure, understand schema relationships, and navigate complex OpenAPI specifications with ease. It provides a split-view interface with a Monaco code editor for editing YAML/JSON specifications and a React Flow-based graph visualization that displays endpoints and schemas as nodes with semantic relationship edges. The core architecture separates OpenAPI semantics from visual representation by extracting a rich relationship model that captures the meaning of connections between components, enabling features like semantically meaningful edge labels, filtering by relationship type, and contextual circular dependency detection.
  </overview>
